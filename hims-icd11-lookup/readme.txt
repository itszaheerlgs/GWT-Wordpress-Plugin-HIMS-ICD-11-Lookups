Full-featured ICD-11 MMS (2025-01) search, browse, code info, postcoordination, history & export for WordPress.

== Description ==
HIMS ICD-11 Lookup connects your WordPress site to the WHO ICD-API v2, giving you:
* Live search with autocomplete
* Browse all 26 ICD-11 chapters
* Code info & postcoordination decoder
* Search history per user
* CSV / JSON export
* 5 shortcodes

== Installation ==
1. Upload the plugin folder to /wp-content/plugins/
2. Activate the plugin
3. Go to ICD-11 > Settings and enter your WHO API credentials
4. Get credentials free at https://icd.who.int/icdapi

== Shortcodes ==
[icd11_lookup]   — Full tool
[icd11_search]   — Search bar only
[icd11_code code="BA00"] — Inline code badge
[icd11_chapters] — Browse chapters
[icd11_history]  — User history table
